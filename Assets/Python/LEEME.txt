PROGRAMA DE VISION ARTIFICIAL PARA EL ROBOT SCARA
==================================================

Este programa detecta objetos por color usando la camara de la laptop
y envia comandos al ESP32 por Bluetooth para controlar el robot.

REQUISITOS:
- Python 3.8 o superior instalado en la computadora.
- Camara de la laptop funcionando.
- ESP32 emparejado por Bluetooth con la computadora.

INSTALACION:
1. Abrir una terminal (CMD o PowerShell).
2. Navegar a esta carpeta:
   cd ruta/al/proyecto/ROBOT_SCARA/Assets/Python
3. Instalar las dependencias:
   pip install -r requirements.txt

USO:
1. Encender el robot y verificar que el ESP32 esta emparejado por Bluetooth.
2. Buscar el puerto COM del Bluetooth:
   - Abrir Configuracion de Windows > Dispositivos > Bluetooth.
   - Buscar "Mas opciones de Bluetooth" > Puertos COM.
   - Anotar el puerto COM de salida del ESP32 (ej: COM5).
3. Abrir Unity y conectar el ESP32 por USB (para la visualizacion).
4. En una terminal separada ejecutar:
   python vision_scara.py --puerto COM5
5. Colocar objetos de color rojo, verde o azul frente a la camara.

COLORES Y COMANDOS:
- ROJO   -> Envia "PICK"  (el robot ejecuta secuencia de agarre)
- VERDE  -> Envia "PLACE" (el robot ejecuta secuencia de colocacion)
- AZUL   -> Envia "HOME"  (el robot vuelve a posicion inicial)

LIMITACIONES:
- Solo detecta colores solidos bien definidos, no formas ni patrones.
- Los comandos son simples (PICK, PLACE, HOME), no trayectorias complejas.
- No recibe retroalimentacion del robot, solo envia comandos.
- La velocidad depende del Bluetooth de la computadora.
- Hay una espera minima de 3 segundos entre comandos para evitar saturacion.

PARA CERRAR:
- Presionar la tecla 'q' en la ventana de la camara.
